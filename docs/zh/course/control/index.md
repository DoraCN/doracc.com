# 第十章 · 控制与仿真

> 本章主题：🦾 控制与仿真

前九章，小莫长了眼睛、耳朵和嘴，还练出了强壮的体力。现在，它要有"手"了。本章我们将 DORA 数据流接入 PyBullet 物理仿真引擎，让 SO-101 五轴机械臂在 3D 窗口中实实在在地动起来——从命令行单关节指令到实时键盘控制再到笛卡尔空间规划，一步一个台阶。

## 本章内容

- **[10.1 控制信号建模](./control-modeling)**：控制信号在 DORA 中的形态——用极简 demo 跑通键盘→DORA→控制指令的回路
- **[10.2 PyBullet 仿真 SO-101](./pybullet-so101)**：从零搭建物理仿真——加载 URDF、关节控制、DORA 仿真节点封装、完整数据流
- **[10.3 可选：真实硬件](./real-hardware)**：从仿真到真机的桥接——接口一致性、SO-101 硬件采购与连接、`.drec` 录制回放替代方案
- **[🎯 小项目⑦：控制仿真机械臂](./project-arm)**：键盘实时控制五轴机械臂，进阶实现笛卡尔空间 IK 控制

## 学完能做什么

- 用 PyBullet 加载任意 URDF 机械臂模型并可视化
- 手写 DORA 仿真节点，把物理引擎封装进数据流
- 用键盘**实时流畅地**操控仿真机械臂的每一个关节
- 理解逆运动学（IK），用空间坐标（而非关节角度）操控机械臂末端
- 在仿真和真实硬件之间自由切换（同样的 DORA 数据流，不同底层驱动）

## 前置要求

- 完成[第四章](../python-node/)、[第五章](../data/)、[第六章](../communication/)
- 理解 DORA 节点的基础写法和 `dataflow.yml` 的定时器（`dora/timer/...`）用法
- 电脑能跑 `uv pip install pybullet`（无 GPU 要求）

:::tip
本章全程纯 CPU 运算，不需要 GPU。PyBullet 的安装一行搞定（`uv pip install pybullet`），三平台通吃（macOS / Windows / Linux）。
:::
