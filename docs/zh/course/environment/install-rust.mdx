# 2.1 Rust 工具链

DORA 是用 Rust 编写的，编译它需要 Rust 工具链。安装推荐使用 **rustup**——Rust 官方的工具链管理器。

## 1. 先检查一下

在动手安装之前，不妨先看看你的电脑上是否已经有了 Rust。打开终端，输入：

```bash
rustc --version
cargo --version
```

输出版本号（如 `rustc 1.90.0`），说明已安装；提示 `command not found`，说明还没装。

DORA 1.0 RC 要求 Rust **≥ 1.88.0**。根据你的情况，选下面一条往下走：

| 你的情况            | 怎么做                                                      |
| ------------------- | ----------------------------------------------------------- |
| `command not found` | → 看「**3. 安装 rustup**」                                  |
| 版本号 ≥ 1.88.0     | → 已经满足要求，直接去 [2.2 Python 与 uv](./install-python) |
| 版本号 < 1.88.0     | → 版本不够，先看下面「**2. 升级已有的 Rust**」              |

---

## 2. 升级已有的 Rust

如果你之前装过 Rust 但版本低于 1.88.0，把工具链升上来就行。

### 用 rustup 升级

```bash
rustup update
rustc --version    # 确认版本号 ≥ 1.88.0
```

### 如果你是用系统包管理器装的

有些同学可能当初用 `apt install cargo` 或 `brew install rust` 装的——这些源的版本通常偏旧。建议先卸载，再按下方「3. 安装 rustup」的方式重装：

<Tabs groupId="os">
<Tab label="Ubuntu/Debian">

```bash
sudo apt remove cargo rustc
```

</Tab>
<Tab label="macOS (Homebrew)">

```bash
brew uninstall rust
```

</Tab>
</Tabs>

:::tip 升级时网络慢？
`rustup update` 默认从国外 CDN 下载，国内可能很慢或超时。可以先设置镜像环境变量再升级，做法和安装 rustup 一样——详见 [2.5（可选）国内镜像加速](./optional-mirrors)。
:::

## 3. 安装 rustup

<Tabs groupId="os">
<Tab label="macOS">

```bash
# 安装 Xcode Command Line Tools（如尚未安装）
xcode-select --install

# 安装 rustup
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 将 Rust 加入当前 shell 的 PATH
source "$HOME/.cargo/env"

# 验证安装
rustc --version    # 应输出版本号（需 ≥ 1.88.0）
cargo --version    # 同上
```

:::tip 国内网络？
如果下载很慢或超时，可以先设置镜像再执行安装命令，参考 [2.5 节](./optional-mirrors)。
:::

</Tab>
<Tab label="Linux">

```bash
# 安装构建必需的系统包
# Ubuntu / Debian:
sudo apt update && sudo apt install -y build-essential git curl
# Fedora / RHEL:
# sudo dnf groupinstall "Development Tools"

# 安装 rustup
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 将 Rust 加入当前 shell 的 PATH
source "$HOME/.cargo/env"

# 验证安装
rustc --version    # 应输出版本号（需 ≥ 1.88.0）
cargo --version    # 同上
```

:::tip 国内网络？
如果下载很慢或超时，可以先设置镜像再执行安装命令，参考 [2.5 节](./optional-mirrors)。
:::

</Tab>
<Tab label="Windows">

Windows 安装 Rust 分四步走：先确定电脑架构 → 下载对应的安装程序 → 运行安装 → 装 C++ 编译工具。下面一步一步来。

如果你还不确定 Rust 是否装过，先在 PowerShell 里敲一下 `rustc`。看到这个画面就说明还没装：

![rustc 未安装时的提示](/rust01.jpg)

好，开始安装。

#### 第一步：判断你的 Windows 是哪种架构

打开 **PowerShell** 或 **命令提示符**（CMD），输入：

```powershell
echo %PROCESSOR_ARCHITECTURE%
```

根据输出的值，找到你对应的情况：

| 输出值  | 含义                                             | 你该下载哪个 |
| ------- | ------------------------------------------------ | ------------ |
| `AMD64` | 64 位 Intel / AMD 处理器（绝大多数 PC）          | x86_64 版本  |
| `ARM64` | 64 位 ARM 处理器（如 Surface Pro X、骁龙笔记本） | aarch64 版本 |

:::details 还有个不常见的情况：64 位系统跑 32 位 CMD
在 64 位系统上用 32 位的命令提示符，可能输出 `x86` 而不是 `AMD64`。确认一下系统到底是不是 64 位：打开 **设置 → 系统 → 关于**，看"系统类型"一栏——如果写"基于 x64"，那还是下载 x86_64 版本。
:::

#### 第二步：下载安装程序

根据上一步的结果，在 **PowerShell** 里执行对应的命令：

<Tabs groupId="win-arch">
<Tab label="x86_64（Intel / AMD）">

```powershell
# 下载 rustup 安装程序到当前目录
curl.exe -o rustup-init.exe https://static.rust-lang.org/rustup/dist/x86_64-pc-windows-msvc/rustup-init.exe
```

</Tab>
<Tab label="ARM64">

```powershell
# 下载 rustup 安装程序到当前目录
curl.exe -o rustup-init.exe https://static.rust-lang.org/rustup/dist/aarch64-pc-windows-msvc/rustup-init.exe
```

</Tab>
</Tabs>

:::tip 下载很慢？
如果下载速度不理想，可以设置国内镜像后再下载（见 [2.5 节](./optional-mirrors)），或者直接用浏览器打开上面那个链接下载，效果一样。
:::

#### 第三步：运行安装程序

下载完成后，在同一个 PowerShell 窗口中执行：

```powershell
.\rustup-init.exe
```

此时会出现一个**文字界面的安装向导**，内容如下：

![rustup 安装向导界面](/rust02.jpg)

**直接敲回车**（或输入 `1` 再回车）——选择默认安装。默认会做三件事：

- 把 Rust 装到 `C:\Users\你的用户名\.cargo\bin\`
- 自动把 Rust 加入系统 PATH
- 安装最新的 stable 版本工具链

之后你会看到进度条在跑（下载 + 安装 Rust 工具链），最后出现 `Rust is installed now. Great!` 就说明装好了。

#### 第四步：让新装的工具生效

装完之后，你当前的 PowerShell 窗口还不认识 `rustc`，需要刷新一下 PATH：

```powershell
$env:Path = [System.Environment]::GetEnvironmentVariable("Path","User") + ";" + "$env:USERPROFILE\.cargo\bin"
```

或者简单一点——**关掉当前 PowerShell，重新打开一个**。

#### 第五步：安装 Visual Studio Build Tools

Rust 编译需要系统的 C++ 链接器，Windows 上通过 **Visual Studio Build Tools** 提供。

下载并运行安装程序：

```powershell
curl.exe -o vs_BuildTools.exe https://aka.ms/vs/17/release/vs_BuildTools.exe
.\vs_BuildTools.exe
```

在"工作负载"页面**勾选「使用 C++ 的桌面开发」**，点击"安装"，等待完成（需要下载几个 GB，耐心等一下）。

:::tip 已经装过 Visual Studio？
如果你电脑上已经有 Visual Studio 2019 或 2022（完整版），且安装时勾了 C++ 工作负载，那 Build Tools 就不用再装一遍了。
:::

#### 第六步：验证安装

一切就绪后，在 PowerShell 里验证：

```powershell
rustc --version    # 应输出版本号（需 ≥ 1.88.0）
cargo --version    # 同上
```

两个命令都输出版本号，恭喜，Rust 工具链装好了！

</Tab>
</Tabs>

## 4. 关于编译速度

首次 `cargo build` 需要下载并编译依赖，可能耗时几分钟到十几分钟，这是正常的。编译产物会被缓存，后续编译会快很多。

国内网络可参考 [2.5 节](./optional-mirrors) 配置 crates 镜像加速。

## 小结

- **先检查**：`rustc --version` 看看是否已安装、版本是否 ≥ 1.88.0。
- **版本不够就升级**：`rustup update` 一条命令搞定。
- **还没装就用 rustup**：macOS / Linux 一条 `curl | sh`，Windows 用 `rustup-init.exe`。
- Windows 额外需要 **Visual Studio Build Tools**（含 C++ 工具集）。
- 国内网络下载慢？看 [2.5（可选）国内镜像加速](./optional-mirrors)。
